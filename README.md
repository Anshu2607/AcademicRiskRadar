
# Academic Risk Radar

### Academic Risk Monitoring and Student Performance Dashboard

Academic Risk Radar is a C# and ASP.NET Core Blazor-based web application designed to help educational institutions visualize academic performance and identify students who may require additional academic support.

The project focuses on presenting academic information through a clean, responsive, and user-friendly interface.

## Project Objectives

- Provide a centralized academic monitoring dashboard.
- Help identify potential academic risk indicators.
- Present student performance information clearly.
- Support academic review and decision-making.
- Deliver a professional, responsive user experience.

## Getting Started

### Prerequisites

- .NET SDK compatible with the project
- Visual Studio Code or Visual Studio
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/AcademicRiskRadar.git
cd AcademicRiskRadar
```

### 2. Restore Dependencies

```bash
dotnet restore AcademicRiskRadar.Web/AcademicRiskRadar.Web.csproj
```

### 3. Run the Application

```bash
dotnet run --project AcademicRiskRadar.Web/AcademicRiskRadar.Web.csproj
```

Open the localhost URL displayed in your terminal.
